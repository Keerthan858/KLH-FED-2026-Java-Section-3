# ATM Transaction Simulator

A simple **ATM Transaction Simulator** developed using Java for the course **Problem Solving using Programming (Java)**.

The program simulates basic ATM operations such as PIN verification, balance checking, depositing money, withdrawing money, and viewing transaction history.

## ⚙️ How the Program Works

1. The user enters the ATM PIN.
2. The program verifies the entered PIN.
3. If the PIN is incorrect, access is denied.
4. If the PIN is correct, the ATM menu is displayed.
5. The user can select:
   - Check Balance
   - Deposit Money
   - Withdraw Money
   - View Transactions
   - Exit
6. Successful deposits and withdrawals are stored in the transaction history.
7. The user can continue performing operations until Exit is selected.
